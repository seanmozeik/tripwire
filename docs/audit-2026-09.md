### Disposition of the former unsupported groups

| Former group                      | Implemented behavior                                                                                | Remaining safety boundary                                                                                                                                  |
| --------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Unresolved binding/runtime state  | Ordinary type, iterator, exception and numeric helpers; `typeof`; explicit interpreter cwd          | Network calls, unknown runtime bindings, and mutations of interpreter environment remain unverified.                                                       |
| Unmodeled callable effects        | Module resolution, process event/timer callbacks, filesystem queries, Bun writes, cwd changes       | Runtime-selected callable implementations must be known. External executable imports remain blocked.                                                       |
| Source with trailing arguments    | Static argv binding for inline and stdin source                                                     | Missing source, variable-width expansion, preload flags, and unresolved path arguments remain blocked.                                                     |
| Value not proved inert            | Standard paths, regex values, checked replacement callbacks and data operations                     | Uninspected coercions, object getters and callable values cannot become inert data.                                                                        |
| Standard-library imports          | Checked contracts for `plistlib`, `asyncio`, `inspect`, Node `util` and `os`                        | Executable third-party imports in those same commands remain blocked; arbitrary library members are not implicitly trusted.                                |
| Iteration forms                   | File/stdin input, tuple targets, single-statement JS bodies, bounded dictionary comprehensions      | Filesystem/runtime-derived entries do not supply verified file paths.                                                                                      |
| Rest/destructuring parameters     | Positional/keyword rest and ordinary array/object patterns, preserving keyword-only defaults        | Unknown expanded argument counts and uninspected binding behavior remain blocked.                                                                          |
| Keyword options                   | Subprocess cwd, standard codec error handling, sequence-matcher options and path-resolution options | Custom error handlers, callbacks and unknown effect-changing options remain blocked.                                                                       |
| `*` and spread                    | Bounded array/call expansion and inert object spread                                                | Runtime expansion cannot shift a supposedly checked argv operand.                                                                                          |
| `Path.resolve` / `readlink`       | Shared resolution of literal paths in a known cwd                                                   | Prior overlapping mutations, unknown process effects, and missing readlink results prevent path authorization.                                             |
| Import separators                 | Dotted and grouped standard-library imports                                                         | Dotted module discovery may execute a parent package and remains blocked.                                                                                  |
| Bindings/assignments              | Tuple assignments, multiple JS declarations, nonlocal assignments and checked member writes         | Runtime environment mutation and uninspected prototype manipulation remains blocked.                                                                       |
| Parser/inspector rejection        | Confirmed that the one audited inline source is truncated mid-string                                | Incomplete code cannot produce a complete inspected program. This is a correct denial.                                                                     |
| Bun file methods                  | Image conversion/write, file write/unlink and read/metadata operations                              | Unknown paths, callbacks and unmodeled file methods remain blocked.                                                                                        |
| Walrus `NamedExpression`          | Inspected ordinary walrus assignments, including the observed while-loop form                       | Comprehension walrus rebinding can affect an outer scope; it remains blocked rather than retaining a stale safe binding.                                   |
| Replacement arguments             | Inert runtime text, Python counts and inspected JS/Python callbacks                                 | Custom coercions and unresolved callbacks remain blocked.                                                                                                  |
| Computed properties/object spread | Known computed keys and spreads over inert data                                                     | Accessors, prototype mutation and spreads containing executable values remain blocked.                                                                     |
| `setdefault` / `finditer`         | Checked dictionary mutation and regex iteration/match data                                          | Mutated containers lose literal authority; match-derived file operands remain unproved.                                                                    |
| `ThrowStatement`                  | Inspect the thrown expression and its constructor arguments                                         | Throwing cannot hide an unchecked effect.                                                                                                                  |
| Dynamic operators                 | Operations on modeled inert values and path values                                                  | Unknown objects may invoke overloaded operators; filesystem-derived objects cannot be treated as verified paths.                                           |
| `ClassDefinition`                 | Plain instance state/methods and the observed restricted HTML parser subclass                       | Implicit hooks such as `__getattr__`, `__del__`, `__eq__`, `__hash__`, `__str__`, `__format__`, iteration hooks and other dunder overrides remain blocked. |

Bun transpilation needs special care: its documented macro support can execute code during transformation. Literal source without imports is inspected; opaque file-derived transpiler input remains denied. [Bun transpiler documentation](https://bun.sh/docs/runtime/transpiler). Python also documents parent-package import during dotted module discovery. [Python importlib documentation](https://docs.python.org/3/library/importlib.html#importlib.util.find_spec).

## Boundaries retained

There are no remaining rows classified merely as “Not yet supported.” The tables above distinguish implemented forms from specific unproved effects, invalid inputs, absent replay filesystem state, and existing policy restrictions. This does not claim that every possible Python or JavaScript construct is modeled.

Uninspected module execution, dynamic imports, reflection/eval, unknown call targets, implicit class hooks, runtime environment mutation, unproved filesystem-derived operands, unverified startup/remote contexts, and analysis-budget exhaustion remain fail closed. These hooks do not establish runtime filesystem containment.
