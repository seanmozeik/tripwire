# September 2026 transcript audit follow-up

## Changes

- Track cwd and the directory stack in the shared shell environment. Invocations and redirects carry cwd through literal `cd`, nested shells, branches, functions, aliases, and supported wrappers. Unknown/missing directories remain unknown. Deletion, protected writes, archive destinations, and inline operations consume this context.
- Add lexical closure scopes, actual argument binding, eager default/call-bearing annotation inspection, merged return states, bounded recursion, and callback/loop invalidation. Mutable containers lose literal authority through every alias. Extend inert JS/Python data operations and extract file-transfer effects.
- Serialize forwarded argv from typed words. Synthetic xargs input stays dynamic and cannot be reparsed as a redirect operator.
- Classify read-only Git branch forms before checking computed global directory arguments; mutating or computed branch options stay blocked.
- Unwrap the requested environment/tool wrappers plus corepack, uvx, busybox, and toybox. Unknown wrapper options fail closed. Project/env-loading wrappers preserve an unverified inline-startup marker while exposing their child to the other policies.

## Boundaries retained

Uninspected module execution, reflection/eval, dynamic imports, unknown call targets, filesystem-derived write/delete/process operands, unverified startup contexts, recursive analysis beyond the budget, and unknown wrapper options remain blocked. Rest/destructuring function parameters and other unmodeled forms in the table remain unsupported. File rename/replace operations check both source deletion and possible destination replacement against the deletion policy.
